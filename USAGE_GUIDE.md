# PlanbookAI - Usage Guide

## 🚀 Getting Started

### Quick Start
1. Open the application
2. You'll see the login page with demo access buttons
3. Click any role button to instantly access that role's interface:
   - **Teacher** - For the complete teaching experience
   - **Admin** - For system administration
   - **Manager** - For business management  
   - **Staff** - For content creation

### First Login (Teacher Role)
Click the "Teacher" button to access the main teaching interface.

## 📚 Teacher Features Guide

### 1. Dashboard
**Purpose**: Overview of your teaching activity and student performance

**What You See**:
- Total questions, students, exams, and average scores
- Quick action cards for common tasks
- Recent activity timeline
- Top performing students
- Topic performance metrics

**Quick Actions**:
- Generate Exercise
- Create Exam
- Grade Papers
- Manage Question Bank

### 2. Question Bank
**Purpose**: Manage all your chemistry questions

**How to Use**:
1. **Create a Question**:
   - Click "Create Question" button
   - Enter question text
   - Select topic from dropdown (e.g., "Atomic Structure")
   - Choose difficulty (Easy/Medium/Hard)
   - Select question type (Multiple Choice recommended)
   - Add answer options
   - Select correct answer
   - Add explanation (optional)
   - Set point value
   - Add tags for organization
   - Click "Create Question"

2. **Filter Questions**:
   - Use search bar to find questions by text
   - Filter by topic using dropdown
   - Filter by difficulty level
   - Combine filters for precise results

3. **Edit a Question**:
   - Click edit icon on any question card
   - Modify fields as needed
   - Click "Update Question"

4. **Duplicate a Question**:
   - Click duplicate icon
   - A copy will be created with "(Copy)" suffix
   - Edit the copy as needed

5. **Delete a Question**:
   - Click delete icon
   - Confirm deletion

### 3. Exercise Generator (AI-Powered)
**Purpose**: Create custom exercises using AI

**How to Use**:
1. Select a **Topic** (e.g., "Chemical Bonding")
2. Choose **Difficulty Level** (Easy/Medium/Hard)
3. Set **Number of Questions** (1-20)
4. Add **Additional Instructions** (optional)
   - Example: "Focus on calculations"
5. Click **"Generate Exercise"**
6. Wait 2-3 seconds for AI generation
7. Review generated questions
8. Options:
   - **Save to Question Bank**: Add all questions to your bank
   - **Download as PDF**: Export for printing
   - **Shuffle**: Generate a new variation

**Tips**:
- Start with 5 questions for quick practice sets
- Use "Medium" difficulty for general assessment
- Add specific instructions for targeted practice

### 4. Exam Generator
**Purpose**: Create comprehensive exams with multiple versions

**How to Use**:
1. Enter **Exam Title** (e.g., "Mid-Term Chemistry Exam")
2. **Select Topics**:
   - Check boxes for topics to include
   - Mix multiple topics for comprehensive exams
3. Set **Questions per Topic** (1-10)
4. Set **Duration** in minutes (15-180)
5. Set **Number of Versions** (1-5) for multiple exam forms
6. Check **"Randomize question order"** (recommended)
7. Click **"Generate Exam"**
8. Review the exam preview
9. Options:
   - **Preview Exam**: Full-screen view
   - **Shuffle**: Reorder questions
   - **Export to PDF**: Generate all versions

**Tips**:
- Use 2-3 versions to prevent cheating
- Include 5-7 questions per topic
- Allow 2-3 minutes per question for timing

### 5. OCR Grading
**Purpose**: Automatically grade scanned answer sheets

**How to Use**:
1. **Select Exam** from dropdown
2. Enter **Student Name**
3. Click **upload box** or drag and drop:
   - Accepted formats: PDF, JPG, PNG
   - Maximum size: 10MB
4. Click **"Grade Answer Sheet"**
5. Wait 3 seconds for OCR processing
6. View results:
   - Overall score and percentage
   - Correct/incorrect breakdown
   - Detailed answer review
7. Click **"Export Result"** to save as PDF

**Tips**:
- Ensure scans are clear and well-lit
- Use standard bubble sheet formats
- Review results before finalizing

### 6. Analytics
**Purpose**: Track student performance and identify trends

**Features**:
- **Student Performance Tab**:
  - Bar chart of average scores
  - Top performers list
  - Individual student trends

- **Topic Analysis Tab**:
  - Performance by chemistry topic
  - Identify weak areas
  - Question count per topic

- **Score Distribution Tab**:
  - Pie chart of grade ranges
  - Percentage breakdowns
  - Class overview

**How to Use**:
1. Switch between tabs to view different analyses
2. Use time period filter (All Time/Month/Week)
3. Hover over charts for detailed data
4. Identify struggling students or topics
5. Plan interventions based on insights

## 💡 Tips & Best Practices

### For Teachers
1. **Build Your Question Bank First**:
   - Start with 20-30 core questions
   - Cover all major topics
   - Mix difficulty levels

2. **Use AI Generation Wisely**:
   - Review all AI-generated content
   - Edit for accuracy and clarity
   - Add explanations to questions

3. **Regular Analytics Review**:
   - Check analytics weekly
   - Identify struggling topics
   - Adjust teaching strategies

4. **Exam Preparation**:
   - Create exams 1 week before test date
   - Generate 2-3 versions
   - Print and review before distributing

### For All Users
1. **Use Search and Filters**: Save time finding content
2. **Tag Everything**: Makes future searches easier
3. **Regular Backups**: Export important content as PDF
4. **Organize by Topic**: Maintain consistent categorization

## 🎯 Common Workflows

### Weekly Teaching Routine
1. **Monday**: Review analytics from previous week
2. **Tuesday**: Create exercises for current topic
3. **Wednesday**: Grade previous assignments
4. **Thursday**: Prepare questions for upcoming quiz
5. **Friday**: Generate next week's exam

### Exam Creation Process
1. Review curriculum coverage
2. Select 3-4 main topics
3. Generate exam with mixed difficulties
4. Preview and adjust
5. Create 2-3 versions
6. Export and print

### Grading Workflow
1. Collect student answer sheets
2. Scan all papers (batch scanning recommended)
3. Upload and grade one by one
4. Export results
5. Record in grade book
6. Review analytics for trends

## ❓ Troubleshooting

### "Question not found"
- Check filters - you may have active topic/difficulty filters
- Use search to locate specific questions

### "Generation failed"
- Ensure you selected a topic
- Try reducing number of questions
- Refresh and try again

### "Upload failed"
- Check file size (max 10MB)
- Ensure file format is PDF, JPG, or PNG
- Try a different file

### "Cannot access page"
- You may not have permission for that role
- Log out and log in with correct role
- Check with administrator
